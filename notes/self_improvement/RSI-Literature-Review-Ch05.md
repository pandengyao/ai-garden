## 5. 权重层自我改进（上）：从自举到自我奖励（2017–2024）

本章讨论权重层的自我改进：模型生成数据，经某种信号筛选或打分后更新同一模型（或其后继）的权重，并可多轮重复。时间上从 2017 年的 Expert Iteration、AlphaZero 到 2024 年底的 WebRL，共 30 篇（本文统计）。贯穿全章的问题有四个：筛选信号来自哪里（规则与执行校验、金标准答案、学习得到的奖励模型、模型自评或人工）；改进器本身（搜索专家、验证器、裁判）是否也被改进；循环能跑几轮才饱和或反转；最外层哪些部分始终固定。总体判断是：这一时期的证据有力支持“有界自我改进”，即外部锚点约束下一到四轮的稳定增益；对“递归（复利）自我改进”的支持，基本只来自规则封闭、奖励不可被策略利用的博弈环境（本文判断）。

### 5.1 搜索—蒸馏式自博弈的先声：ExIt 与 AlphaZero

Expert Iteration（ExIt）把序列决策拆成规划与泛化：树搜索规划新策略，深度网络泛化这些规划，再用网络策略引导搜索、提高新规划的强度[^187]。每轮由上一代学徒（apprentice）网络自博弈产生局面，训练新学徒模仿搜索专家，再用新学徒更新专家，即“专家改进”[^187]。与只能模仿固定初始专家的方法不同，ExIt 能为自己制造更强的专家，因而整个训练过程都有专家可用[^187]。这是本章最早也最干净的元层级实例：产生训练目标的改进器（搜索专家）随被改进者一起变强（本文判断）。

从零训练的 ExIt 在棋类游戏 Hex 上击败了已公开发布的最新一代 Olympiad 冠军程序 MoHex 1.0[^187]。10,000 次搜索迭代的 ExIt 对同等迭代数的 MoHex 胜率为 75.3%，对 100,000 次迭代的 MoHex 为 59.3%[^187]。策略每轮稳定提升，后期学徒明显强于早期专家[^187]，且报告结果时训练曲线仍未显示收敛[^187]。作者也给出了每轮增益的上界：学徒与改进后专家之间的差距决定新学徒每轮性能的上界[^187]。实现上，ExIt 每一步从头重做模仿学习并丢弃旧数据集，在线版本则改为汇总迄今全部数据[^187]；网络权重在每轮重新初始化后再在新数据上训练[^187]。跨轮累积的是数据与专家强度，而不是同一组参数（本文判断）。

ExIt 的作者把 AlphaGo Zero 视为 ExIt 的独立开发版本[^187]。AlphaZero 则把 AlphaGo Zero 的做法推广为单一算法[^120]：从随机对弈出发、除规则外不给任何领域知识，24 小时内在国际象棋、将棋和围棋上达到超人水平，并各击败一个世界冠军程序[^120]。训练信号是规则判定的终局结果[^120]，更新后的参数直接用于后续自博弈[^120]。它取消了 AlphaGo Zero 的择优门控（新选手须以 55% 的优势胜过最佳选手才替换之），只维护一个持续更新的网络[^120]。AlphaZero 训练 4 小时（300k 步）超过 Stockfish，不到 2 小时（110k 步）超过 Elmo，8 小时（165k 步）超过 AlphaGo Lee[^120]。代价是 5,000 块第一代 TPU 生成自博弈、64 块第二代 TPU 训练网络[^120]，且每种棋类单独训练一个实例[^120]。

这两项工作确立了此后 LLM 自训练反复借用的模板：以搜索（或“采样加筛选”）作为策略改进算子，产出优于当前策略的目标，再蒸馏回网络（本文判断）。它们也给出了模板能够持续复利的条件：奖励由规则在终局给出、不会被策略“说服”；训练问题由自博弈产生、随对手变强自动变难（本文判断）。去掉择优门控意味着每次参数更新都直接进入下一轮数据生成，这种做法只有在奖励不会被策略利用时才安全（本文推断）。后文 LLM 循环中的饱和与反转，大多可追溯到这两个条件之一不成立（本文推断）。

### 5.2 在可验证的自生成数据上自举：从 STaR 到 Qwen2.5-Math

STaR 把 ExIt 列为灵感来源[^209]。它相当于把“搜索专家”换成了“带答案校验的采样”（本文判断）。其循环是：为大量问题生成推理（rationale）；答错时以正确答案为提示重新生成（rationalization）；在所有最终答对的推理上微调；重复[^209]。每收集一批新数据都从原始预训练模型重新训练，以避免过拟合[^209]。在 GPT-J（6B）上，STaR 在 CommonsenseQA 上与大 30 倍的微调模型相当（72.5% vs. 73.0%）[^209]。算术任务跑 16 轮后准确率为 89.5%[^209]。GSM8K 上直接微调为 5.8，带 rationalization 的 STaR 为 10.7[^209]；这些结果是在 36 轮不带 rationalization 的迭代、外加 10 轮带 rationalization 的迭代之后得到的[^209]。其局限预告了此后答案过滤式方法的边界：首轮要求 few-shot 表现高于随机，GPT-2 连算术都无法自举[^209]；对解题“有用”的数据偏差会被放大[^209]；不加 rationalization 时循环最终不再能解出新题，因为做错的题得不到训练信号[^209]。STaR 的轮数虽多，实质是在固定题库上提取答案校验所能覆盖的那部分能力（本文判断）。

Haluptzok 等人受 AlphaZero 启发，让模型自己合成编程谜题与解答并由 Python 解释器过滤[^84]，在自己的已验证数据上微调后测试准确率提高一倍以上[^84]。Neo-2.7B 微调 1 个 epoch 后的 Pass@100：基线 7.5%，自生成并经验证 20.6%，Codex 生成未经验证 21.5%，Codex 生成并经验证 38.2%[^84]。作者认为相当一部分提升来自解释器过滤[^84]；第二轮收益已很小，因成本两轮即止[^84]。增益主要取决于过滤信号和生成者强度，数据是否由模型“自己”生成并不关键（本文判断）。

LMSI 把信号换成自洽性：对无标注问题采样多条思维链，用多数投票筛出高置信路径再微调[^109]。PaLM-540B 的 GSM8K 从 74.4% 升到 82.1%[^109]，六个数据集提升 1.1% 到 7.7%，全程不用真值标签[^109]。但自我改进后最优采样温度高于原来的 0.7，作者归因于输出熵降低[^109]。就本文所读，该文只报告了一轮自训练；熵降低也提示多数投票式自标注主要在锐化已有分布（本文判断）。

ReST 把“采样—过滤—微调”写成 Grow/Improve 结构的离线 RL：Grow 由当前策略生成数据，Improve 在过滤后的数据上微调[^177]。每个后续 Improve 步都显著提高平均奖励[^177]，第二次 Grow 在 IWSLT 2014 De-En 上再加 5.3 分[^177]。但奖励模型只是人类偏好的代理：以人工评估看一次 Grow 最好，尽管奖励随 Grow 次数继续上升[^177]；作者也提示重复 Grow 会增加对奖励模型过拟合的风险[^177]。ReST-EM 在 ReST 基础上做了修改[^133]，流程为“采样、按二值反馈过滤、微调、重复数次”[^133]，且每轮都从基础预训练模型微调以减少漂移[^133]。PaLM 2-L 在 MATH 和 APPS 上的测试准确率提升分别为 6.34% 和 6.4%[^133]，显著超过只用人类数据微调[^133]。但 MATH 的测试增益在第一轮后变小，APPS 第二轮即回退[^133]。训练集表现随轮数线性上升而测试集不升[^133]；作者认为超过几轮后收益递减，提示可能在少量训练题上过拟合[^133]；方法还需要人工收集的题集和人工设计或学习得到的奖励函数[^133]。

V-STaR 指出上述方法只用正确解，丢弃了往往占很大比例的错误解[^48]，转而用正确与错误解以 DPO 训练验证器[^48]，标签来自真值答案或测试用例[^48]。迭代使生成器变好，生成器又为验证器提供更难的负例[^48]；验证器在推理时从多个候选中选优[^48]。多轮之后推理器与验证器都逐步变好，测试准确率比已有方法高 4% 到 17%[^48]，在 MBPP 上，验证器各轮间的增益还大于生成器各轮间的增益[^48]。这是本章少见的“改进器被迭代改进且贡献更大”的证据（本文判断）。但把验证器放进训练环筛数据没有带来实质增益[^48]。

Iterative RPO 针对的是迭代偏好优化在推理任务上收效甚微的问题[^257]。它每轮以“答对者胜、答错者负”构造偏好对，用带 NLL 项的 DPO 训练，并从上一轮模型继续训练[^257]；作者认为 NLL 项至关重要[^257]。Llama-2-70B-Chat 的 GSM8K 从 55.6% 升到 81.6%，MATH 从 12.5% 升到 20.8%[^257]。GSM8K 逐轮为 73.1、78.0、81.1、81.6[^257]，作者亦称推理能力提升到最后会饱和[^257]。

ReST-MCTS\* 与 AlphaLLM 把 ExIt/AlphaGo 式的搜索引回 LLM 自训练（本文判断）。ReST-MCTS\* 批评只看结果的过滤：答案正确不代表整条推理正确[^14]。给定 oracle 最终答案，它把每一步导向正确答案的概率估计为过程奖励[^14]，这些奖励既用于继续训练过程奖励模型，也用于挑选策略自训练的轨迹[^14]。相同 token 预算下，迭代训练的价值模型在 MATH 上做验证达到 48.5%，高于 self-consistency 的 42.5%[^14]。但在 LLaMA-3-8B-Instruct 的三基准均分上，第 0 轮零样本与 few-shot 基线分别为 24.78 和 28.99，ReST-MCTS\* 两轮后为 29.02[^14]；作者说明评测只用零样本，few-shot 基线仅作对照[^14]。AlphaLLM 借鉴 AlphaGo，组合提示合成、MCTS 与三个评判模型[^262]，头条结果是 GSM8K 从 57.8 升到 92.0、MATH 从 20.7 升到 51.0[^262]。但这依赖推理时的 ηMCTS 解码，贪心解码只有 73.7 和 23.6，而 Llama-2-70b 经 SFT 后贪心解码为 69.3[^262]。评判模型在框架内保持静态[^262]。AlphaLLM 自称无需额外标注[^262]，但作者也写明它使用了最终答案标注[^262]。搜索带来的增益有相当一部分没有被蒸馏进权重，这与 ExIt 的学徒—专家差距上界是同一个问题（本文判断）。

Quiet-STaR 沿另一方向推广 STaR：在每个 token 处生成“思考”以解释后续文本，用 REINFORCE 提高有助于预测的思考的概率[^203]。在网页文本上继续预训练 Mistral 7B 后，零样本 GSM8K 从 5.9% 升到 10.9%[^203]，且无需针对任务微调[^203]。这里的“验证器”是语料自身的似然，因而可推广到无标注文本（本文判断）。代价是每生成一个 token 前要先生成许多 token[^203]。

Qwen2.5-Math 把上述做法组装成工业流水线，称自我改进贯穿预训练、后训练与推理[^214]。上一代 Qwen2-Math-72B-Instruct 合成数学预训练数据，构成超过 1 trillion tokens 的 Qwen Math Corpus v2[^214]，前一版语料约为 700 billion tokens[^214]。后训练中奖励模型驱动 SFT 数据迭代，更强的 SFT 模型又用于重训奖励模型[^214]；RL 奖励由与金标准答案比对的规则验证器和奖励模型共同构成[^214]。Qwen2.5-Math-7B-Instruct 的表现超过上一代 72B 模型，MATH 在 CoT 与 TIR 设置下分别为 83.6 和 85.3[^214]。这里的元层级更新是真实的：奖励模型跨轮重训，上一代模型为下一代写语料；但每一步都锚定在标注答案上，就本文所读也未见逐环节的消融（本文判断）。

本节方法的共同结构是：训练题目（或生成题目所用的种子）与语料由人提供，最终的校验依据（金标准答案、解释器、多数投票规则、文本似然或固定的奖励模型）不随循环改变，模型只负责生成候选（本文判断）。V-STaR、ReST-MCTS\* 与 Qwen2.5-Math 虽然重训验证器或奖励模型，其信号仍锚定在真值答案或与金标准答案比对的规则验证器上（本文判断，依据见[^48][^14][^214]）。在这一结构下，有外部校验的改进是可靠的，上界由题库覆盖的能力决定，多数方法两到三轮后增益显著收窄（本文判断）。

### 5.3 自生成指令与 AI 反馈：Self-Instruct、Constitutional AI 及其后继

对齐与指令跟随没有金标准答案，信号来源转向启发式过滤、人写原则和 AI 标注器（本文判断）。

Self-Instruct 从 175 个人工种子任务出发[^197]，让现成 LM 生成新指令与实例，过滤低质或相似者后放回任务池[^197]，再用这些数据微调生成它们的同一个 GPT-3[^197]。在 52K 条自生成指令上微调后，GPT-3 在 SuperNI 上绝对提升 33%[^197]，ROUGE-L 从 6.8 升到 39.9，接近 InstructGPT001 的 40.8[^197]。但抽样审查显示，输出正确且可接受的只有 58%，全部字段都有效的为 54%[^197]。指令回译（Humpback）把人工过滤规则换成模型自评：种子模型为网页文档生成指令（自增广），再挑出高质量样本（自整理）[^245]，然后用改进后的模型重新整理并训练，共两轮[^245]。整理器确实在变好：在作者标注的 250 条开发集上，M1 的精确率与召回率为 0.52 与 0.44，高于 M0 的 0.44 与 0.09，但远低于 GPT-4 的 0.88 与 0.92[^245]。65B 的 Humpback 在 GPT-4 判分的 Alpaca 排行榜上为 83.71，高于 Guanaco 的 71.80[^245]。关键的反面结果是，只用自增广数据、不做自整理时，指令跟随不升，甚至随数据增加而下降[^245]；自整理数据单独使用也不如直接扩充种子数据，与种子数据联合训练时才有大幅提升[^245]。

Constitutional AI（CAI）把人类监督压缩为一份原则清单，不用任何标注有害输出的人类标签[^27]。监督阶段在自我批评后的修订回答上微调[^27]；RL 阶段由模型比较两个样本，以 AI 偏好训练偏好模型并作为奖励，即 RLAIF[^27]。不过偏好模型是混合的，有用性仍用人类标签[^27]。RL-CAI 显著比 RLHF 更无害[^27]，但过度训练会出现 Goodharting，表现为过于严厉或套话式的回答[^27]。作者设想今后可用 AI 监督做迭代式“在线”训练[^27]。就本文所读，该文本身并未进行这种迭代（本文判断）。SELF-ALIGN 沿用 Self-Instruct 机制并引入原则[^246]，在模型按原则生成的回答上微调基座[^246]。它以不到 300 行人工标注（含 16 条原则）得到的 Dromedary 在若干基准上超过 Text-Davinci-003[^246]；代价是 Verbose Cloning 步骤损害多选基准[^246]，模型偶尔生成违背原则的幻觉[^246]。

RLAIF vs. RLHF 表明 AI 标注在摘要与对话任务上可与人类标注相当[^266]，无害对话中 RLAIF 的无害率为 88%，RLHF 为 76%[^266]。但主实验的标注模型远大于被训练的策略[^266]。同尺寸标注器的 RLAIF 以 68% 被偏好于 SFT，作者强调这并非严格的自我改进，因为标注器与初始策略不是同一检查点[^266]。反馈模型与初始策略为同一检查点的 d-RLAIF 在有用对话上对 SFT 胜率 66%，作者称之为严格的自我改进[^266]。所有设定中标注器都不更新（本文判断）。RLAIF 与 RLHF 策略都倾向生成更长回答[^266]，摘要末尾还常出现多余符号，可能源于 reward hacking[^266]。

Toolformer 用“能否降低后续 token 损失”自监督地筛选模型自己采样并执行的 API 调用，再在增广数据上微调自身[^228]。6.7B 的 GPT-J 由此在多项下游任务上超过更大的 GPT-3[^228]，但最小的模型无从获益[^228]，样本效率也很低[^228]。作者把迭代应用该方法作为改善样本效率的一种可能办法提出[^228]。就本文所读，论文本身只做了一遍（本文判断）。MART 让对抗 LLM 与目标 LLM 共演化：前者每轮针对更新后的目标生成更强的攻击，后者做安全微调[^88]，目标模型以安全与有用两个奖励模型的反馈来衡量[^88]。4 轮后违规率按奖励模型评估最多降 84.7%，按人工评估降 53.7%[^88]；最后一轮在生成的对抗提示上收敛[^88]，且仍需约 2,400 条人工整理的种子提示[^88]。OMNI 用基础模型充当“兴趣模型”，为 RL 智能体挑选下一个任务[^308]，作者视之为 AI 自选学习任务、促进自我改进[^308]。在 Crafter 中 OMNI 智能体学会 82 个任务，只用学习进度的基线为 55 个[^308]。但作者预期，按 Goodhart 定律，兴趣模型一旦成为优化目标就会暴露病理[^308]。

本节工作把人类输入从逐条标注压缩为种子、原则和固定的评判模型，但没有消除它；除 Humpback 的整理器外，CAI、RLAIF 的标注器和 MART 的奖励模型都不随训练更新（本文判断，依据见[^27][^266][^88]）。RLAIF 的作者估计 LLM 标注比人工标注便宜 10 倍以上[^266]。这一时期 AI 反馈的主要贡献是降低标注成本，而不是建立能自我强化的信号源（本文判断）。

### 5.4 模型自任裁判：自我奖励、元奖励与评估器的自举

自我奖励类方法让同一个模型既生成回答又为其打分[^66][^256]。裁判就是被训练的模型本身，因而随训练一起变化；若裁判能力随之提升，元层级就被打开（本文判断）。本节证据表明这一打开是真实的，但很浅，缺乏外部锚点时还会反转（本文判断）。

Self-Rewarding Language Models 的出发点是，从人类偏好训练的奖励模型可能受限于人类水平，冻结后也无法在训练中继续改进[^66]。它让模型以 LLM-as-a-Judge 提示为自己的候选回答打分[^66]，下一轮从上一轮初始化并以 DPO 训练[^66]。种子是在 Open Assistant 上微调的 Llama 2 70B[^66]，指令种子为 3200 条人类样本[^66]。对 GPT-4 Turbo 的 AlpacaEval 2.0 胜率三轮依次为 9.94%、15.38%、20.44%[^66]。裁判本身也在变好：与人类排序一致的成对准确率从 78.7% 升到 80.4%，再到 81.7%[^66]。作者的保留同样重要：这一效应在真实场景中很可能饱和[^66]；只跑了三轮、单一设定[^66]；生成长度随迭代增加[^66]；训练奖励与最终评估（GPT-4）都由语言模型给出，需要更深入的分析[^66]；多数 NLP 基准与基线持平[^66]。

Meta-Rewarding 认为已有方法主要改进回答而非判断，导致迭代训练很快饱和[^134]；判断能力不提升时，演员（actor）的训练可能很快饱和，甚至过拟合奖励信号（reward hacking）[^134]。它引入第三个角色“元裁判”评估模型自己的判断[^134]，并在分数接近时选较短的回答以抑制长度偏差[^134]。Llama-3-8B-Instruct 在 AlpacaEval 2 上的长度控制胜率从 22.92% 升到 39.44%[^134]。在 Arena-Hard 上，加长度控制的 Self-Rewarding 四轮为 23.2%、26.3%、28.2%、27.3%，第 4 轮回落，Meta-Rewarding 为 25.1%、27.4%、27.6%、29.1%[^134]。与同一轮的 Self-Rewarding 相比，其裁判与 GPT-4 判断的一致性最多高出 +12.34%（Self-Chosen Pairs，第 2 轮）[^134]。边界同样清楚：没有人类标注，裁判质量只能以与 gpt-4-1106-preview 的相关性衡量[^134]；5 分制使回答越来越接近满分，改进难以检测[^134]；元裁判的位置偏差阻碍了第 3 轮的提升，裁判打分膨胀加速了饱和[^134]；裁判对非自生成回答的评估改进有限[^134]。

Self-Taught Evaluators 直接以评估器为改进对象，只用合成数据[^137]。它把针对改写后相关指令的高质量回答当作“较差”回答来构造对比对[^137]，训练裁判输出推理与判断，只保留判断正确的样本，并逐轮重复[^137]。Llama3-70B-Instruct 的 RewardBench 从 75.4 升到 88.3，而从同一种子用有标注的 HelpSteer2 训练只到 85.6[^137]。逐轮总分为 83.9、86.0、87.5、87.7、88.3，其中较容易的 Chat 子项从 97.6 降到 96.6[^137]；MT-Bench 上与人类判断的一致率从种子的 77.8 只变为 78.9[^137]。方法还依赖一个已与人类偏好相当对齐的种子模型[^137]。第三轮后总分增益明显收窄，而人类一致率基本不动，说明评估器的进步集中在 RewardBench 覆盖的那类困难对比上（本文判断）。

CREAM 给出了本章最清楚的反转曲线（本文判断）。作者观察到，约 7B 的模型上自我奖励的收益在某些情况下可能几轮后减弱，并假设原因是奖励系统中累积的偏差[^256]。它认为提示打分可能只适用于 Llama-70B 这类较大的模型[^256]，因而改用 DPO 隐式奖励[^256]，并用上一轮奖励模型的排序与当前排序的一致性来正则化训练[^256]。在 Llama-3 的六轮实验（五个基准平均）中，SFT 后为 80.24[^256]。未正则的 SRLM 从 M2 的 80.99 逐轮降到 M6 的 68.59[^256]。CREAM 在 M4 达到 83.65，之后小幅回落到 82.73[^256]。作者据此认为 CREAM 在第 4 轮收敛，而 SRLM 从第 2 轮起就开始退化[^256]。采用提示打分的 P-SRLM 在 M2 只有 77.62，低于 SFT[^256]，作者称提示打分对小模型无效，从第一轮起性能就下降[^256]。由于 SRLM 与 P-SRLM 分列，前者应与 CREAM 一样使用隐式奖励，六轮退化并非提示式裁判所独有（本文推断）。把奖励模型换成外部 InternLM2、并借助下游任务标签的 Oracle 变体总体最好[^256]，作者据此认为不可靠的奖励是此类方法的关键挑战[^256]；包括 CREAM 在内，整体排序准确率也不超过 70%[^256]。

SPIN 与 SPPO 代表另一条路线：自博弈，但锚点在模型之外（本文判断）。SPIN 让新模型区分上一轮的自生成回答与人类标注回答[^8]，其目标的全局最优只在策略与人类数据分布一致时取得[^8]。zephyr-7b-sft-full 的 Open LLM Leaderboard 均分从 58.14 升到 63.16，逐轮增益为 +2.66、+1.32、+0.85、+0.19[^8]。在同一 SFT 数据集 Ultrachat200k 上继续做 SFT 会进入平台甚至下降，SPIN 只用其中 50k 子集就能逐轮提升[^8]；但作者承认固定的人类目标分布给性能设了上限[^8]。SPPO 把对齐视为常和博弈，以迭代自博弈逼近纳什均衡[^152]，只用 60k 条提示和 0.4B 参数的偏好模型 PairRM[^152]。Mistral-7B 的长度控制胜率三轮为 24.79、26.89、28.53，同表中迭代 DPO 为 23.81、24.23、22.30[^152]。但在 Open LLM Leaderboard 上，DPO、IPO 和 SPPO 都在第一或第二轮后下降，作者归因于对齐税[^152]。

三类工作确实打开了元层级：Self-Rewarding 的裁判三轮内成对准确率提高约三个百分点，Meta-Rewarding 专门训练裁判，Self-Taught Evaluator 以评估器本身为对象（本文判断，依据见[^66][^134][^137]）。它们共享三个限制（本文判断）。其一，裁判的改进集中在模型自身的分布上，人类一致性近乎持平（本文判断，依据见[^134][^137]）。其二，回答质量多由 GPT-4 类模型评判，与训练信号同属一类，存在循环验证之虞（本文判断，依据见[^66][^152]）。其三，缺少外部锚点的小模型上，自我奖励会在数轮后反转，外部奖励模型仍是上界（本文判断，依据见[^256]）。SPIN、SPPO 没有崩溃，是因为锚点不随模型漂移，代价是天花板也由锚点决定（本文判断，依据见[^8][^152]）。

### 5.5 学会自我改进：自我纠错与自生成课程

另一种“元”的做法不是改进裁判，而是把改进本身变成模型可学的技能，或让模型的失败生成下一阶段的任务（本文判断）。

RISE（Recursive Introspection）的出发点是，即使最强的闭源 LLM 被告知出错后，也不能持续改进自己的回答[^38]。它把单轮的“提示—oracle 答案”数据集构造成多轮 MDP[^38]：展开当前模型 k−1 轮后接一个改进回答，改进回答来自自蒸馏（从自身多次采样取最好）或更强的模型[^38]。迭代时从基础模型重新开始、在全部轮次的数据上训练，比从上一轮检查点继续更好[^38]。在 GSM8K 上，完全使用自身数据时 LLaMa3-8B 提升 8.2%、Mistral-7B 提升 6.6%[^38]。无 oracle 时，LLaMa2 经第 1、2 轮训练后的五轮内省增益在 GSM8K 上分别为 15.1% 和 17.7%[^38]。五轮内省使 Mistral-7B 提升 23.9%，GPT-3.5 只提升 4.6%[^38]。SCoRe 的作者对此评价较低：RISE 主要依赖 oracle 教师监督，其自我纠错训练的初步结果在五轮内只有小幅改进[^132]。收集同策略数据之前，RISE 通常还先用更强模型生成的多轮轨迹做一次监督微调，作者称之为“知识增强”阶段[^38]。RISE 的训练不超过两轮，监督来自自身时不超过一轮[^38]。纯自蒸馏版本未超过微调模型在第一轮多数投票（m5@t1）上的表现[^38]，作者认为它必须先追平 best-of-N 采样才可能超越[^38]。作为对照，只靠提示的 Self-Refine 在没有 oracle 提示或人类反馈时会使所有模型的表现下降[^38]。

SCoRe 认为自我纠错在现代 LLM 中一直基本无效[^132]，提出完全使用自生成数据的多轮在线 RL[^132]，但仍假定可以访问评估输出的奖励函数[^132]。其第二阶段奖励的是“朝向自我纠错的进展”而非最终正确性[^132]。Gemini 1.0 Pro 和 1.5 Flash 的自我纠错在 MATH 与 HumanEval 上分别提升 15.6% 和 9.1%[^132]。在离线纠错轨迹上做 SFT，要么分布错配，要么坍缩到单一而无效的纠错模式[^132]；SCoRe 只训练了一轮自我纠错，后续轮次未必同样有效[^132]。这两项工作把改进器从环外的裁判搬进了推理过程，推理时可多步复用；但训练仍需 oracle 答案或奖励函数，且只训练一到两轮，训练层面的复利尚无证据（本文判断，依据见[^38][^132]）。

WebRL 用自演化课程训练基于开源 LLM 的网页智能体[^180]，针对的是 DigiRL 只在固定任务集上更新策略的问题[^180]。它从失败尝试中生成新任务，配合结果监督奖励模型（ORM）和自适应 RL[^180]。新任务由 GPT-4o 生成，每个阶段从中选出 500 条满足筛选条件的指令[^180]。所谓“自演化”是以智能体自己的失败为种子，出题者并不是智能体本身（本文判断）。新任务只在评论家打分介于 0.05 和 0.75 之间时保留[^180]，不可完成的任务经人工审查归纳后由 GPT-4o 提示排除[^180]。为抑制漂移，它约束当前阶段的策略不过度偏离上一阶段[^180]，回放缓冲区只存各阶段的成功轨迹[^180]。WebArena-Lite 上 Llama-3.1-8B 的成功率从 4.8% 升到 42.4%，超过 GPT-4-Turbo 的 17.6%[^180]。按网站拆开的训练曲线中，除 Map 外各站点都呈明显上升趋势，Map 则先升后降[^180]。ORM 的准确率约为 80%[^180]，作者承认持续改进很大程度上取决于 ORM[^180]，在线探索带来的分布漂移可能导致遗忘与退化[^180]。WebRL 改进的是任务分布，论文中未见 ORM 随课程更新（本文判断）。与 OMNI 合看，“自己出题”比“自己打分”更稳妥，因为成败仍由环境或固定奖励判定；但两者的评估器都冻结在循环之外（本文判断，依据见[^308][^180]）。

### 5.6 横向发现：饱和、反转、锚点与“数据复利”

第一，饱和是常态，通常出现在第二到第四轮（本文判断）。编程自博弈第二轮收益已很小[^84]；ReST-EM 的 APPS 第二轮回退[^133]；ReST 以人工评估计一次 Grow 最好[^177]。SPIN 的逐轮增益从 +2.66 降到 +0.19[^8]，SPPO 从 +7.69 降到 +1.64[^152]；Self-Taught Evaluator 第三轮后 RewardBench 只从 87.5 升到 88.3[^137]；MART 最后一轮收敛[^88]。没有在二到四轮内饱和的例外有三类（本文判断）。一类是规则封闭的博弈，ExIt 报告结果时训练曲线仍未收敛[^187]。一类是 STaR 式循环：每轮从原模型重训，在固定题库上重复到性能进入平台为止[^209]。还有一类是 WebRL 的在线课程，其提示对比实验训练了八个阶段[^180]，按网站拆开的曲线中多数站点持续上升，Map 则先升后降[^180]。后两类的信号仍由金标准答案或环境奖励函数锚定（本文判断）。

第二，当裁判就是模型自己且不加约束时，饱和会变成反转（本文判断）。CREAM 的六轮实验中，未正则的自我奖励从 M2 的 80.99 跌到 M6 的 68.59[^256]；Meta-Rewarding 报告的 Self-Rewarding 基线在 Arena-Hard 第 4 轮从 28.2% 回落到 27.3%[^134]。外部学习的奖励模型也有类似现象（本文判断）。ReST 的奖励随 Grow 次数上升，人工评估却以一次 Grow 最好[^177]，CAI 过度训练后出现 Goodharting[^27]，RLAIF 策略在摘要末尾添加多余符号[^266]。

第三，真正保持不动的是锚点（本文判断）。推理类循环依赖人工收集的题集与正确答案，ReST-EM 与 Iterative RPO 的作者都把它列为前提[^133][^257]，Qwen2.5-Math 的 RL 奖励也包含与金标准答案比对的规则验证器[^214]。对齐类循环的锚点是人写的种子与原则：Self-Instruct 的 175 个种子任务[^197]、SELF-ALIGN 的 16 条原则[^246]、MART 约 2,400 条种子提示[^88]。SPIN 以人类 SFT 数据为目标分布[^8]，SPPO 以人类偏好训练的 PairRM 为裁判[^152]。评测端还有隐性锚点：Humpback 与 SPPO 的指令跟随结果由 GPT-4 判分[^245][^152]。没有一项工作让模型改动自身的训练算法、损失函数或循环结构，元层级的改动止步于打分器和任务分布（本文判断）。

第四，相当一部分方法跨轮累积的是数据而非权重（本文判断）。STaR 与 ReST-EM 每轮回到原始或基础模型[^209][^133]，RISE 从基础模型重训并累积全部轮次的数据[^38]。V-STaR 的生成器每轮从预训练模型出发、在累积的正确解上微调[^48]，ExIt 每轮重新初始化网络权重[^187]。沿用权重的有 AlphaZero 的单一持续更新网络[^120] 和 Iterative RPO，后者反而不复用前几轮收集的数据[^257]。Self-Rewarding 与 Meta-Rewarding 也在上一轮模型上继续训练[^66][^134]，WebRL 则需要 KL 约束和回放缓冲区来抵御漂移[^180]。就本章文献而言，参数层面持续复利的证据主要来自博弈自博弈（本文判断）。

| RISE[^38] | oracle 答案 +（自）蒸馏 | ≤2 | Mistral-7B 五轮内省 +23.9% | 自蒸馏版未超过 m5@t1 |
| SCoRe[^132] | 奖励函数 + 进展塑形 | 1 | MATH 自我纠错 +15.6% | 只训练一轮 |
| WebRL[^180] | ORM + 环境；GPT-4o 出题 | 多阶段（提示对比实验为八个阶段） | 成功率 4.8% → 42.4% | ORM 准确率约 80% |

### 5.7 小结（本文判断）

1. 有界自我改进的证据是充分的：只要存在外部锚点（规则、解释器、金标准答案、单元测试），用自生成数据训练能在一到四轮内带来稳定增益，且可用不依赖 LLM 评判的指标测得。依据见[^84][^133][^257]。
2. 复利式改进只在封闭博弈中可见。ExIt 的训练曲线未收敛、AlphaZero 从随机对弈到超人，依赖的是不可被策略操纵的规则奖励和随对手变强而自动变难的问题分布，本章所涉的 LLM 循环没有一个同时满足这两个条件。依据见[^187][^120]。
3. LLM 自训练循环普遍在二到四轮内饱和；本章最长的自评循环（六轮）在不加正则时显著退化，加正则后也只是在第四轮收敛、此后小幅回落，而非持续上升。依据见[^256][^8][^152]。
4. 元层级已被打开但很浅：整理器、验证器、过程奖励模型和 LLM 裁判都有被迭代改进的实例，但改进幅度有限、集中在模型自身的分布上，多以 GPT-4 判断或合成构造的标签衡量；这些实验大多只跑二到五轮，其中 Self-Taught Evaluator 在第三轮后已趋平。依据见[^134][^137][^48]。另见[^66][^14][^245]。
5. 没有一项工作改动训练算法、损失函数或循环结构本身；最外层（种子、原则、答案或奖励函数、外部评测器）始终由人固定，“递归”止步于打分器和任务分布。依据见[^197][^27][^214]。
6. 信号来源决定上限与风险，“谁来打分”比“谁来生成”更关键：经验证的自生成数据与未经验证的更强模型数据效果相近，学习的奖励模型与人工评估脱节，模型自评在小模型上会反转。依据见[^84][^177][^256]。
7. 跨轮复利的载体常常是数据而非参数：STaR、ReST-EM、RISE 等每轮回到基础模型，只把数据和产生数据的生成器带入下一轮；沿用权重的循环中，WebRL 与 CREAM 分别借助 KL 与回放、跨轮一致性约束来抵御漂移或偏差累积。依据见[^209][^38][^180]。另见[^133][^256]。
8. 自我纠错与自生成课程把改进器变成模型可学的技能或任务分布，是通向递归自我改进的另一条路径；但 RISE、SCoRe 只训练一到两轮，WebRL 与 OMNI 的评估器保持冻结，尚不足以证明复利。依据见[^38][^132][^308]。
