## 7. 冻结权重下的自我改进：提示、上下文、记忆与技能

本章讨论不更新主模型权重的自我改进：经验被写进模型之外的制品，包括修改意见、反思、洞见、提示、上下文手册、可执行技能乃至记忆架构，再由同一个冻结模型以这些制品为条件继续工作。就本章各方法而言，主模型权重在改进循环内都保持冻结（本文判断）。部分例外是 DSPy 可以选择微调流水线中的小模型[^175]，MemSkill 用强化学习训练一个轻量 MLP 控制器[^271]。全章围绕三个问题展开：改进保存在哪里、作用域多大；改进器本身是否也被改进，最外层还剩哪些固定部件；信号来自执行与测试、环境奖励、标签数据、LLM 评判还是模型自评。总体判断是：这条路线提供了大量有界自我改进的证据；环内复利只以技能组合的形式出现；“改进改进器”的设计都只上升一个元层级，最外层算子固定、运行很短，还不构成递归（复利）自我改进的证据（本文判断）。

### 7.1 上下文内自我反馈：Self-Refine、Reflexion 与谈判自博弈

最早一批工作确立了最基本的形式：冻结模型借助语言反馈，在上下文中改进输出或策略。它们证明了可行性，也暴露出三条约束：能力门槛、信号质量和快速饱和（本文判断）。

Self-Refine 让同一个 LLM 先生成初稿，再为自己的输出写反馈并据此修改，历史反馈与输出拼接进提示，最多迭代 4 轮[^269]。在 7 项任务上，使用 GPT-3.5 和 GPT-4 时，它比同一模型的一次性生成平均绝对提升约 20%[^269]。Reflexion 把策略参数化为“记忆编码加一组 LLM 参数”：智能体对任务反馈做语言反思，存入情节记忆供后续试验使用，受上下文限制通常只存 1–3 条[^268]。信号可以是二元环境反馈、预定义启发式，或 LLM 二分类、自写单元测试这类自评估[^268]。Reflexion 在 HumanEval 上的 pass@1 达到 91%，此前 GPT-4 为 80%[^268]。相对强基线，它在 AlfWorld 上用 12 个学习步骤取得 22% 的绝对提升[^268]。谈判自博弈把同一思路放进多智能体博弈：前几轮历史与 AI 评论者的反馈作为上下文示例，迭代改进其中一方的谈判策略，以成交价格为指标[^219]。

能力门槛在三项工作中一致出现。Self-Refine 要求基座有足够的少样本或指令遵循能力，Vicuna-13B 在修改环节明显吃力[^269]。Reflexion 发现，明确给出自我纠正是更强、更大模型才涌现的能力[^268]。谈判中只有 gpt-4、claude-v1.3 这类强且对齐良好的模型能持续改进，较弱的模型要么不懂规则，要么用不上反馈[^219]。信号质量是第二条约束。Self-Refine 在数学上增益有限，因为模型判断不了答案是否有错，若有外部来源指出错误，增益可达 5% 以上[^269]。Reflexion 的自写测试在 MBPP Python 上假阳性率为 16.3%，在 HumanEval Python 上为 1.4%[^268]。饱和是第三条约束。Self-Refine 的边际改进随迭代递减[^269]。只有 gpt-4 能在 5 轮中持续提升，其他模型约 3 轮后饱和，更好的价格还伴随更高的谈崩风险[^219]。Reflexion 在需要创造性探索的 WebShop 上四次试验仍无起色[^268]。在 Meta-TTL 以 Jericho 文本游戏所做的对照中，Reflexion 的平均 W-AUC 在 ID 游戏上低于不学习的 Static 基线（0.173 对 0.195），在 OOD 游戏上仅略高（0.241 对 0.228）[^270]。

这一层支持的是有界自我改进：改进对象是单个实例的输出或单个任务内的几条反思，作用域随任务结束而终止，反思程序由人手写、从不改变，瓶颈在于判断“哪里错了”而不在生成（本文判断，依据见[^269][^268]）。

### 7.2 经验积累：技能库、洞见记忆与上下文手册

第二批工作把保留的制品扩展为跨任务积累的库。这带来了本章最清楚的环内复利证据，即技能组合；同时表明，决定积累是否有益的是写入、合并和遗忘的规则，而这些规则在各文中都由人设计并保持固定（本文判断）。

**可执行技能。** Voyager 由自动课程、可执行代码技能库和融合环境反馈、执行错误与自验证的迭代提示组成，通过黑盒查询使用 GPT-4，新技能经验证后存入向量数据库[^90]。复杂技能由简单程序组合而成，作者认为这让能力随时间快速复合[^90]。与此前最佳方法相比，它获得的独特物品多 3.3 倍，解锁科技树里程碑最多快 15.3 倍[^90]。没有技能库时智能体后期趋于停滞，去掉自验证则发现的物品数下降 73%[^90]。GPT-4 获得的独特物品是 GPT-3.5 的 5.7 倍，作者明确说 GPT-3.5 和开源模型提供不了所需的代码质量[^90]。LATM 让 GPT-4 编写 Python 工具并用单元测试验证，再交给 GPT-3.5 使用，性能与两个角色都用 GPT-4 相当，推理成本显著降低[^277]。但每个任务只有 3/3/240 条训练/验证/测试实例，GPT-3.5 Turbo 作为制造者在难任务上全部失败，改进已有工具也留作未来工作[^277]。OS-Copilot 的 FRIDAY 自主提出任务课程，评论者用 LLM 给新工具打 0–10 分，只保留高于 8 分的工具[^181]。它在 GAIA level-1 上取得 40.86%，此前最佳为 30.3%[^181]。但关闭自主学习时它已达到 36.56[^181]。也就是说，领先的一半以上在不学习时就已存在（本文判断）。SkillWeaver 让 GPT-4o 在每个网站上探索 160 次迭代，把练习经验提炼为 Playwright API，由 LLM 奖励判断任务是否完成，并用自动生成的测试检验 API[^154]。它在 WebArena 和真实网站上的相对成功率分别提升 31.8% 和 39.8%，足够多的探索之后还出现了调用多个简单 API 的组合式 API[^154]。

**自然语言经验记忆。** ExpeL 在训练任务上收集经验，用 ADD、UPVOTE、DOWNVOTE、EDIT 维护洞见列表，测试时以成功轨迹作示例[^166]。它把自己与 Reflexion 对立：不靠反复尝试同一任务，而靠跨任务积累[^166]。不重复尝试时，它在 ALFWorld 上以 59% 超过 Reflexion 第三轮的 54%[^166]。HotpotQA 消融中，ReAct 为 28.0，手写洞见为 32.0，ExpeL 为 39.0[^166]。Dynamic Cheatsheet（DC）把记忆放到测试时的查询流上：同一个黑盒模型兼任生成者与筛选者，筛选者看不到真值标签，只保留简洁、可迁移的片段[^275]。Claude 3.5 Sonnet 在 AIME 2024 上从 23% 升到 50%，GPT-4o 在 Game of 24 上发现并复用一个 Python 解法后从约 10% 升到 99%[^275]。关键对照是附上全部未筛选历史（FH）：GPT-4o 在 AIME 2024 上从 20.0% 的基线降到 6.7%（Table 2 对应格为 13.3，方向一致），DC-RS 则达到 40.0%[^275]。ReasoningBank 从 LLM 评判的成功与失败轨迹中提炼策略条目，新条目直接追加、不做剪枝[^148]。与无记忆智能体相比，它在三种主干上把 WebArena 总成功率提高 +8.3、+7.2 和 +4.6[^148]。在 SWE-Bench-Verified 上，Gemini-2.5-flash 的解决率从 34.2 升到 38.8[^148]。在 WebArena-Shopping 子集上做 k=5 的并行扩展时，无记忆的 Best-of-5 只从 39.0 升到 42.2，配合 ReasoningBank 则从 49.7 升到 55.1[^148]。

**上下文手册与语义优势。** ACE 受 DC 的智能体式设计启发，把适应拆为生成者、反思者、筛选者三个角色，三者用同一个 DeepSeek-V3.1，筛选者产出的增量条目由非 LLM 逻辑确定性合并[^89]。它点名了两种失效：简短偏置（优化坍缩为简短通用的提示，作者以 GEPA 为例）和上下文坍塌（反复整体重写逐步侵蚀细节）[^89]。在 AppWorld 上，整体重写使上下文在第 60 步时有 18,282 个 token、准确率 66.7，下一步骤缩到 122 个 token，准确率 57.1，低于不适应基线的 63.7[^89]。ACE 在智能体任务上比强基线高 10.6%，在金融任务上高 8.6%，适应延迟平均降低 86.9%[^89]。Training-Free GRPO 把 GRPO 的组内比较搬进上下文：参数 θ 冻结，由 LLM 对每组 rollout 内省出“语义优势”，写入外部经验库[^276]。在冻结的 DeepSeek-V3.1-Terminus 上配合 ReAct，它只用 100 道领域外题目、零梯度更新、约 18 美元，就把 AIME24/AIME25 的 Mean@32 从 80.0%/67.9% 提到 82.7%/73.3%[^276]。

这些系统同样受制于能力门槛和信号质量（本文判断）。DC 的收益与模型规模强相关，小模型难以利用，混入记忆的错误启发式也会被同等放大[^275]。Training-Free GRPO 用在 QwQ-32B 上只得到 25.5% 的 pass@1，低于其 ReAct 基线的 27.5%[^276]。缺少可靠反馈（真值标签或执行结果）时，ACE 和 DC 都可能退化，上下文会被误导性信号污染[^89]。FRIDAY 的评论者在没有真值时难以判断子任务是否完成，ReasoningBank 的 LLM 评判也会引入噪声[^181][^148]。

DC 的完整历史对照和 ACE 的坍塌案例从两端说明，决定积累是否有益的是筛选规则：不加筛选地追加会稀释洞见，整体重写会抹掉细节，两者都可能跌破无适应基线，条目化的增量更新是共同补救（本文判断，依据见[^275][^89]）。这些规则由人设计、运行中固定，ReasoningBank 只追加不剪枝，ExpeL 承认终身学习还需要额外检索，记忆在更长时间尺度上如何增长和老化尚无检验（本文判断，依据见[^148][^166]）。复利方面，Voyager 和 SkillWeaver 的组合式技能是能力在制品层面的叠加，新技能以旧技能为构件，但它局限在单一环境或网站之内，课程与筛选规则不变，扩大的是覆盖面而非改进速率（本文判断，依据见[^90][^154]）。

### 7.3 提示与程序优化：在离散文本空间中搜索

提示优化把自我改进写成离散文本空间中的黑盒优化：LLM 生成候选，带标签的训练、开发或留出集打分，搜索算法由人设计并固定。它的增益可复现、样本效率高，上限则受标签集、过拟合和基座知识约束（本文判断）。

OPRO 让 LLM 读取包含既往解与分数的元提示来生成新解，评估后再写回元提示[^184]。最佳提示比人工提示在 GSM8K 上最多高 8%，在 BBH 上最多高 50%[^184]。以 PaLM 2-L 打分的零样本 GSM8K 上，“Take a deep breath and work on this problem step-by-step.” 得到 80.2，“Let's think step by step.” 为 71.8[^184]。EvoPrompt 让 GPT-3.5 充当遗传算法（GA）或差分进化（DE）的算子，依据开发集分数改进提示种群[^55]。它在 BBH 的 22 个任务上都找到了更好的提示，DE 变体最高提升 25%、平均 3.5%[^55]。PromptAgent 用蒙特卡洛树搜索规划提示改写：gpt-3.5-turbo 收集错误，gpt-4 给出错误反馈作为动作，奖励是留出集表现[^51]。它在 BBH 上相对人工提示取得 28.9% 的相对提升[^51]。DSPy 把 LM 流水线抽象为文本变换图，编译器为每个模块自举示例，使 GPT-3.5 上的简单程序从 33% 升到 82%[^175]。MIPRO 在没有模块级标签和梯度的条件下优化各模块的指令与示例，用 Llama3-8B 时在七个程序中的五个上领先，最多高 13%[^56]。TextGrad 把 LLM 的自然语言批评当作“文本梯度”，由领域无关的 TGD 优化器更新变量[^121]。它在提示优化上与 DSPy 在 Word Sorting 和 GSM8k 上相当，在 Object Counting 上高 7%[^121]。GEPA 采样系统轨迹，用自然语言反思诊断问题、提出提示更新，并在 Pareto 前沿上保留各实例上表现最好的候选，权重始终不变[^165]。在 GPT-4.1 Mini 上，它把合计分从 53.03 提到 65.22，MIPROv2 为 58.67，TextGrad 为 59.14[^165]。

这些增益的证据强度不一（本文判断）。OPRO 的训练准确率常比测试高 5%–20%，且必须有训练集来计算准确率[^184]。EvoPrompt 在 BBH 上用于选择的开发集取自测试集，GPT-3.5 的结果只有一个种子[^55]。PromptAgent 的错误反馈可能把实例特有的细节注入任务提示[^51]。

**与权重空间 RL 的样本成本比较。** 这是本节最有分量的证据（本文判断）。在 Qwen3 8B 的六项任务上，GEPA 的合计分为 54.85（+9.62），GRPO 为 48.91（+3.68），基线为 45.23[^165]。GEPA 每项预算为 1,839 到 7,051 次 rollout，GRPO 每项 24,000 次[^165]。在 IFBench 上，GEPA 用 678 次 rollout 得到 38.61%，GRPO 用 24,000 次得到 35.88%[^165]。但 GEPA 在 AIME-2025 上不及 GRPO（32.00 对 38.00），GRPO 一方用的是 LoRA，GEPA 的大部分预算花在只用于候选选择的验证上[^165]。Meta-TTL 的反思式外循环以 350 对 1,920 次 rollout 持平或超过用 GRPO 训练的元智能体[^270]。在匹配的 Qwen3-8B 设定中，在线 SFT、在线 GRPO 等更新行动者参数的方法增益更小，且在不同游戏间不稳定[^270]。Training-Free GRPO 则把冻结的 671B 模型与在 32B 模型上训练的 RL 方法比较，后者通常需要数千个训练样本、成本超过 10,000 美元[^276]。两者基座不同，这只能说明成本差距，不能说明同一模型上孰优孰劣（本文判断）。综合来看，当差距在于如何调用模型已有的知识与技能时（如 IFBench、HotpotQA、HoVer），上下文空间优化的样本效率远高于这些比较中的 RL 基线（LoRA 或小模型上的 GRPO），而当差距在于知识或推理能力本身时，这一优势消失，GEPA 在 AIME 上不及 GRPO，metaTextGrad 在 GPT-4o-mini 的 AIME 2024 上也没有显著增益（本文判断，依据见[^165][^274]）。

**简短还是详尽。** GEPA 报告，它的提示比 MIPROv2 的最多短 9.2 倍，且总体上表现越好的优化器产出的提示越短[^165]。ACE 把这种倾向称为简短偏置，并在 AppWorld 离线设定中比 ReAct + GEPA 高 11.9%[^89]。但 ACE 也承认，HotPotQA 往往更受益于简洁的高层指令，Game of 24 这类固定策略的游戏可能只需一条可复用规则[^89]。Meta-TTL 则发现，GEPA 的提示含有大量任务特定的事实和解法，对已见任务有利，对未见任务用处较小[^270]。分歧的实质不在长短，而在制品保存的是可迁移的程序性知识还是特定任务的事实（本文推断）。ACE 的长手册在工具与领域知识密集的智能体和金融任务上占优，GEPA 在 Qwen3 8B 上的最大增益则出现在 HotpotQA（多跳问答）和 HoVer（多跳事实核验）上，分歧可能主要来自任务类型（本文推断，依据见[^89][^165]）。

本节方法只改任务提示或程序参数，元提示、算子、搜索算法和编译器都固定，唯一例外是 MIPRO++ 对提议策略的元优化（本文判断）。信号几乎都来自带标签的数据，这使增益可以度量，也带来选择泄漏与过拟合的风险（本文判断）。

### 7.4 改进改进器：只上升一个元层级

一组工作把改进器本身当作优化对象，包括变异提示、提议策略、优化器、记忆架构、记忆技能、自我改进策略、验证器和评分指标。它们的共同结构是恰好上升一层：内层改进任务制品，外层改进内层的改进程序，最外层算子（通常是一个强模型加一段固定提示）保持不变（本文判断）。

**变异提示与优化器。** Promptbreeder 同时演化任务提示和改写任务提示的变异提示，后者由 LLM 以自指方式生成并在演化中改进[^30]。一阶超变异把超变异提示 “Please summarize and improve the following instruction:” 接到变异提示上，以生成新的变异提示[^30]。种群为 50 个单元，通常演化 20–30 代，适应度在随机训练批次上评估[^30]。它在 PaLM 2-L 的零样本 GSM8K 上以提示 “SOLUTION” 得到 83.9%，高于 OPRO 的 80.2%[^30]。去掉任一自指算子几乎在所有情况下都有害，但提示拓扑保持固定，只有提示内容被适配[^30]。MIPRO++ 把提议策略参数化并用贝叶斯模型选择，在 ScoNe 和 HotPotQA 上优于 MIPRO，在 HoVer 上大致相当[^56]。metaTextGrad 指出，基于 LLM 的优化器由人手工设计，本身并未被优化[^274]。它用 o1 作元优化器，改写 TGD、ADAS-TG 等优化器的提示，并决定它们的组合与顺序[^274]。在 GPT-4o-mini 上，四个基准的平均验证/测试准确率为 0.56/0.53，零样本 MIPROv2 为 0.49/0.47[^274]。一个元优化周期中，元优化器层只消耗约 2.5k token，程序层约 400k[^274]。

**记忆架构与记忆技能。** MemEvolve 是双层的：内循环在固定的记忆系统下填充经验库，外循环元学习记忆架构本身，即编码、存储、检索、管理四个模块的程序实现[^272]。候选架构按任务成功率、token 消耗和延迟做非支配排序，元演化算子由 GPT-5-mini 担任[^272]。它报告最多 17.06% 的提升，但双层演化只跑 3 轮，每轮只保留一个架构并扩展出 3 个后代，每个候选只在 60 条轨迹上评估[^272]。MemSkill 把记忆构建操作改写为可演化的技能，从 Insert、Update、Delete、Skip 四个基本技能出发，由 LLM 设计者每 100 个训练步审查困难样例并修改技能[^271]。设计者本身是固定的，消融中“去掉设计者”即把技能库固定为四个初始原语[^271]。LoCoMo 消融（LLM 评判分）中，完整方法在 LLaMA/Qwen 上为 53.82/54.14，去掉设计者后降到 46.50/36.15[^271]。

**自我改进策略。** Meta-TTL 认为，Reflexion、Self-Refine 式的语言反馈和记忆积累都是手工设计的自我改进策略[^270]。它的内循环由元智能体在回合之间改写冻结的 Gemini-3-Flash 行动者的系统提示，外循环由提议者生成候选元提示，只有在验证任务上的平衡改进分数（BIS）为正时才替换[^270]。同一主干下，它在 ID 任务上的平均 W-AUC 比最强基线在 Jericho 上高 23%，在 WebArena-Lite 上高 12%[^270]。架构和模型相同、但自我改进策略未经优化的“朴素元智能体”，在 Jericho 的 OOD 游戏上平均 W-AUC 为 0.286，Meta-TTL 为 0.414[^270]。这一差距可以直接归因于学到的改进策略（本文判断）。元训练运行 12–15 轮，API 费用约 30–70 美元，但 Jericho 的 ID 评测复用了元训练游戏[^270]。

**验证器与评分指标。** CoEvoSkills 让技能生成器与替代验证器共同演化：替代测试通过后，隐藏的真值 oracle 在新环境中重跑技能，只回传一个不透明的成败比特[^273]。在 SkillsBench 上，它的通过率为 71.1%，无技能基线为 30.6%，人工整理的技能为 53.5%[^273]。去掉替代验证器后降到 41.1%，两种一次性自生成技能的基线只有 32.0% 和 30.7%[^273]。演化曲线在第 0 轮与无技能基线相当，第 3 轮以 63% 超过人工技能，第 5 轮收敛到 75%[^273]。但这一个比特在演化中决定技能部署与否，另有 10 个任务在预算内始终没有收敛[^273]。

MetaSkill-Evolve 明确以递归为目标。作者认为已有的技能演化只改进任务技能，改进程序写一次就固定，因而是自我改进而非递归自我改进[^122]。它让元技能 m=(ψ,σ,α,π,ε) 采用与任务技能相同的 Markdown 格式，由同一条五智能体流水线在慢循环上改写，作者称之为“有界的一层递归”[^122]。五个智能体共享一个冻结的 Gemma-4 31B 主干[^122]。在留出测试上，它比单层演化基线在 OfficeQA/SealQA/ALFWorld 上分别高 +6.38/+8.05/+1.92 分[^122]。元更新间隔 H=2 最好，OfficeQA 从 H=2 到 H=8 掉了 9.1 分[^122]。但流水线的角色与连接固定，默认只有五轮迭代、两次元更新，评测只覆盖三个精选基准，“固定元过程会停滞”也只是假设[^122]。

Double Ratchet（论文题为 “Who Grades the Grader?”）让评分指标本身演化：在小型检测器组合的空间中搜索，以与十个锚定样例的一致性为选择标准，锁定测试集从不被指标演化读取[^278]。在 MBPP+ 上，演化指标与隐藏真值的一致性提高 0.21（p=0.014），超过它所包含的裸 LLM 评判[^278]。在三个任务上，它保留了真值或人工评分细则所带来提升的 88–110%[^278]。关键发现是负面的：去掉锚定守卫后，指标塌缩为恒通过的检测器，而它训练技能的效果与正常指标一样好，因此下游任务得分无法验证自我演化的评估器[^278]。作者手写的报告评分细则也在一百轮内被技能钻了空子，独立的外部评判在 88% 的有效配对中更偏好基线[^278]。

**本节判断。** 各设计都恰好上升一层且最外层固定：Promptbreeder 的超变异提示与拓扑、metaTextGrad 的 o1 元优化器、MemEvolve 的元演化算子、Meta-TTL 的提议者与 BIS 准则、MetaSkill-Evolve 的流水线角色与间隔 H 都不被改动，没有一篇展示第二个元层级（本文判断，依据见[^30][^274][^122]）。上一层带来的增量为正但幅度中等，且来自很短的运行（本文判断，依据见[^272][^122][^270]）。外层算子往往是更强的模型，metaTextGrad 的元优化器就需要 o1 或 Claude-3.5-Sonnet，因此“改进器的改进”在相当程度上是把强模型的判断注入循环（本文推断，依据见[^274]）。MetaSkill-Evolve 两层共用同一主干和流水线，是最接近自我应用的设计，但证据还很薄（本文判断）。评估器是这一层最薄弱的环节：多数系统的评估器位于循环之外、不被改动，是防止自我改进退化为自我欺骗的锚（本文判断）。CoEvoSkills 和 Double Ratchet 把评估器拉进循环，就必须在更外层放一个更硬的锚，即一比特的隐藏 oracle，或十个锚定样例、锁定测试集与循环外的更强评判（本文判断，依据见[^273][^278]）。元层级每上升一层，都需要一个不随系统演化的外部参照，目前只证明了它在一层上可行（本文判断）。

### 7.5 文本制品的跨模型迁移与持久性

冻结权重路线有一个权重更新没有的性质：改进存在可读、可移植的文本或代码里，可以脱离产生它的模型。多篇论文报告了正向迁移，但迁移多发生在强模型到弱模型之间或同代前沿模型之间，依赖消费方的能力，任务特定的内容迁移较差（本文判断）。

早期证据是“强造弱用”：GPT-4 制造的工具让 GPT-3.5 使用者达到两个角色都用 GPT-4 的水平[^277]。SkillWeaver 中强智能体合成的 API 让较弱的 GPT-4o-mini 智能体在 WebArena 上最多提升 54.3%[^154]。Voyager 能在新的 Minecraft 世界中用已学的技能库从零解决新任务[^90]。后来的工作报告了跨模型家族的迁移。MemSkill 只用 LLaMA 训练，技能不经重训即迁移到 Qwen[^271]。MemEvolve 用 GPT-5-Mini 演化的记忆系统无需人工适配即可迁移到 Kimi K2 和 DeepSeek V3.2，其中 Kimi K2 在 WebWalkerQA 上提升 17.06%[^272]。CoEvoSkills 用 Claude Opus 4.6 演化的技能迁移到来自五家公司的另外六个模型，各自比无技能基线提升约 35–44 个百分点[^273]。

迁移也并不总是有效：metaTextGrad 在 GPT-4o-mini 上优化的优化器用于 Claude 3 Haiku 时，Dyck 测试准确率为 0.35，ADAS-TG 为 0.34，验证集上则是 0.32 对 0.35[^274]。相对 ADAS-TG 几乎没有优势（本文判断）。PromptAgent 的专家级提示可能让 GPT-2、LLaMA 等较小的模型显著退化[^51]。FRIDAY 在底层 LLM 更换时性能可能剧烈变化[^181]。MemEvolve 复现的许多人工记忆系统不能带来稳定提升，ExpeL 在三个基准上全部表现不佳[^272]。

持久性的作用域差别很大（本文判断）。Self-Refine 把历史反馈与输出拼接进当前提示[^269]。论文没有描述跨任务的记忆（本文判断）。Reflexion 在同一任务的多次试验之间保留 1–3 条反思[^268]。CoEvoSkills 的技能在演化阶段只在当前任务内保留，通过 oracle 后才部署给目标智能体[^273]。ExpeL、DC 和 ReasoningBank 则在任务之间累积[^166][^275][^148]。跨任务持久的制品对推理基础设施有直接影响（本文判断）。DC 的作者指出，顺序式的记忆更新给需要独立推理的大规模并行或批处理任务带来困难[^275]。ACE 的上下文比 GEPA 长，但作者认为大部分上下文可由 KV cache 复用，服务成本和显存不随之线性增长[^89]。学习成本因此部分转成了推理侧的状态管理问题，包括前缀缓存、记忆版本和并发一致性（本文推断）。制品的可读性是权重更新所没有的（本文判断）。Meta-TTL 的外循环不依赖梯度，产出的是可读的元提示而非模型权重[^270]。Double Ratchet 演化出的是可检查的表达式，而不是不透明的评判[^278]。但可读不等于可靠（本文判断）。SkillWeaver 在在线评测中仍需人工在执行前核验所有动作的安全性[^154]。

迁移证据支持一个更精确的描述：这条路线产出的主要是可移植的程序性知识，质量上限由生产它的模型决定，能否被利用取决于消费它的模型（本文判断，依据见[^154][^273][^271]）。如果制品能跨代保存，每一代模型都可以在上一代的制品库上继续积累，但本章没有论文检验多代累积，也没有检验旧制品在更强的模型上是助力还是噪声（本文判断）。

### 7.6 小结（本文判断）

以下各条为本章小结（本文判断），每条给出所依据的文献。

- **冻结权重的自我改进真实、廉价，但有界。** 增益集中在单个任务或领域，通常几轮到十几轮内饱和；它放大已有能力而不创造能力，弱模型普遍无法受益。依据见[^219][^269][^268]；另见[^276][^274][^90]。
- **主要约束是信号质量，不是生成能力。** 自评漏检数学错误，自写测试会误报，无可靠反馈时上下文会被污染；有执行、测试或真值的地方增益更稳。依据见[^269][^268][^89]。
- **跨任务积累给出了本章最清楚的环内复利证据，但筛选规则是固定的隐藏改进器。** 技能组合出现在两个系统中；写入与合并规则决定积累有益还是有害，而这些规则都由人设计。依据见[^90][^154]；筛选规则的依据见[^275][^89]。
- **小预算下，上下文空间优化的样本效率明显高于这些比较中的权重空间 RL（LoRA 或小模型上的 GRPO），但补不了知识或推理能力的缺口。** 依据见[^165][^270][^276]；反例见[^274]。
- **“改进改进器”目前恰好只有一层。** 最外层算子固定，运行只有数轮，对单层基线的增量为正但中等；没有第二个元层级，也没有能改写自身顶层程序的算子。依据见[^30][^274][^272]；另见[^270][^271][^122]。
- **评估器完整性是递归的约束条件。** 评估器一旦进入循环，就必须在更外层放置不随系统演化的锚；下游任务得分无法验证自我演化的评估器，代理指标在百轮量级内就会被钻空子。依据见[^278][^273]。
- **制品可迁移，为跨代积累留下通道，但尚未检验。** 技能与记忆架构能跨模型家族迁移，多为强到弱，任务特定的制品迁移较差；尚无多代累积实验。依据见[^154][^273][^272]；另见[^271][^270]。
- **对全文主线的含义。** 本章证据较强地支持“有界自我改进”，多篇论文有隔离制品或元层级的消融；对“递归（复利）自我改进”的支持弱：环内有组合式复利，跨元层级没有加速回报，上限由冻结主干和外部评估器共同决定。依据见[^122][^90][^278]。
